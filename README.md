# ticketmate-release

Public companion repository for [Ticket Mate](https://github.com/Dalibaba/ticketmate). It hosts:

- **The landing page** — served via GitHub Pages at <https://dalibaba.github.io/ticketmate-release/>.
- **The Sparkle update feed** (`appcast.xml`) that installed copies of Ticket Mate poll for updates.
- **Release binaries**, attached to this repository's [GitHub Releases](https://github.com/Dalibaba/ticketmate-release/releases).

Source code lives in the private [`ticketmate`](https://github.com/Dalibaba/ticketmate) repository.
